# Triage labels

- needs-triage: maintainer evaluation is needed.
- needs-info: reporter information is needed.
- ready-for-agent: fully specified work suitable for an agent.
- ready-for-human: human implementation is needed.
- wontfix: work will not be actioned.

Each canonical role maps to the identically named tracker label. Apply these exact strings when a skill names a role. Edit this mapping if the tracker vocabulary changes.
